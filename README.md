## 🚀 Featured projects

### 🎵 [NyasaPlayer](https://github.com/Kanyandula/NyasaPlayer) — music playback for mobile & automotive

A multi-module music player built with **Kotlin, Jetpack Compose, and Media3/ExoPlayer**. It brings together mobile and Android Automotive experiences, background playback, Firebase-backed authentication and content, and shared playback infrastructure. The architecture also explores local persistence and offline use.

`Kotlin` `Compose` `Media3/ExoPlayer` `Firebase` `Android Automotive`

### 🔔 [NotifyBridge](https://github.com/Kanyandula/NotifyBridge) — Android notifications to MQTT

Forwards Android notifications to a local MQTT broker so they can appear in **Home Assistant**, without a cloud relay. The project explores Android notification-listener and background-service constraints, reliable delivery, localisation across multiple locales, Gradle convention plugins in `build-logic`, and a **Docker/Mosquitto test rig**.

`Kotlin` `Coroutines` `MQTT` `Home Assistant` `Local-first` `Docker`

[Read the engineering case study](https://ephraimkanyandula.com/work/notifybridge)

### 📱 [Nyasa](https://github.com/Kanyandula/Nyasa) — Android publishing client

The native companion to [NyasaBlog](https://nyasablog.com). Creators can register, authenticate with tokens, and write and publish posts from their phones. It uses a multi-module Kotlin architecture, with a **Jetpack Compose migration in progress**, a shared error model across features, and Detekt checks in CI.

`Kotlin` `Compose` `Hilt` `Retrofit` `Room` `Coroutines/Flow`

### ✍️ [NyasaBlog](https://github.com/Kanyandula/BlogPost) — publishing platform in production

A **Django 5.2** publishing platform behind [nyasablog.com](https://nyasablog.com), deployed on a **DigitalOcean** droplet. It includes a rich-text editor, token-based authentication, a REST API serving Android clients, and static assets hosted on S3. The project covers backend development, testing, and practical deployment operations.

`Python` `Django` `Django REST Framework` `PostgreSQL` `S3` `Nginx/Gunicorn`

### 🛠️ [claude-statusline](https://github.com/Kanyandula/claude-statusline) — published Claude Code CLI

A configurable status line for Claude Code, with `init`, `preview`, `config`, and `uninstall` commands. Published to [npm](https://www.npmjs.com/package/@kanyandula/claude-statusline) through **GitHub Actions**, with **110 automated tests** documented in the project.

`JavaScript` `Node.js` `CLI` `GitHub Actions` `Testing`

### 🎬 [ComposeMovieApp](https://github.com/Kanyandula/ComposeMovieApp) — online & offline movie search

An Android app for exploring movies and TV shows using **The Movie Database API**, with online and offline search and unit tests. Built with Kotlin and Jetpack Compose.

`Kotlin` `Compose` `Retrofit` `Room` `Unit tests`
