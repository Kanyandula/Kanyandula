## 🚀 Featured Projects

### [Nyasa](https://github.com/Kanyandula/Nyasa) — publishing platform, Android client
The mobile companion to [nyasablog.com](https://nyasablog.com). Creators register, authenticate with tokens, and write and publish posts from their phone. Multi-module Kotlin with a Compose migration in flight, a shared error model across features, and detekt in CI.

`Kotlin` `Compose` `Hilt` `Retrofit` `Room` `Coroutines/Flow`

### [NyasaPlayer](https://github.com/Kanyandula/NyasaPlayer) — music streaming
A modern streaming app built on Media3/ExoPlayer with Firebase for auth and content, background playback, a fully Compose UI, and an Android Automotive build.

`Kotlin` `Compose` `Media3/ExoPlayer` `Firebase` `Automotive`

### [NotifyBridge](https://github.com/Kanyandula/NotifyBridge) — Android → MQTT bridge
Forwards Android notifications to an MQTT broker so they land in Home Assistant. Notification listener service, localisation across multiple locales, convention plugins in `build-logic`, and a Docker test rig running Mosquitto.

`Kotlin` `Coroutines` `MQTT` `Home Assistant` `Docker`

### [NyasaBlog](https://github.com/Kanyandula/BlogPost) — Django site in production
The Django 5.2 platform behind [nyasablog.com](https://nyasablog.com), deployed on a DigitalOcean droplet with S3 static assets, a rich-text editor, and a REST API serving the Android clients. Built test-first, with a security-hardened auth flow.

`Python` `Django` `DRF` `PostgreSQL` `S3` `Nginx/Gunicorn`

### [claude-statusline](https://github.com/Kanyandula/claude-statusline) — published npm CLI
A configurable statusline for Claude Code with `init` / `preview` / `config` / `uninstall` commands, released through GitHub Actions and covered by 110 tests.

`JavaScript` `Node.js` `CLI` `GitHub Actions`

### [ComposeMovieApp](https://github.com/Kanyandula/ComposeMovieApp) — offline-first movie search ⭐
Online and offline search for movies and TV shows from TheMovieDB API. Written in Kotlin with Jetpack Compose and covered by unit tests.
